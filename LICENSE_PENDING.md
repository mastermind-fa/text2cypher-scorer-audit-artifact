# Licence status

**No licence is active yet.** The recommended licence for the project-authored code in this repository is the **MIT
License**. It takes effect only when the authors approve it, at which point a `LICENSE` file with the MIT text is added
here and `CITATION.cff` is updated accordingly.

**Scope once active.** The MIT licence will cover only the project-authored code and documentation in this repository.
It does not cover:
- third-party scorer code, which is fetched from its original repositories at pinned commits and never redistributed
  (`third_party/`);
- third-party benchmark data (CypherTurn, Mind the Query, BIRD), which is fetched, not included;
- the evaluation dataset, which is released separately under its own licence.

Until a licence is active, all rights are reserved by the authors.
