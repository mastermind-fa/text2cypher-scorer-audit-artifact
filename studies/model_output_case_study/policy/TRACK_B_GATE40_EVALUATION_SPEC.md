# S55B prospective Gate40 evaluation specification — OWNER APPROVAL PENDING

**PROJECT FACT:** The S54 protocol froze a first-40 viability floor of 15% per model (at least 6/40) and called for an “official scorer.” No executable, complete Mind the Query official prediction comparator has been verified in the local sparse checkout. Its README describes data validators; the paper gives a broad execution-accuracy definition, not exact normalization, timeout and failure rules. Thus this is a **substantive pre-result amendment proposal**, not an assertion of an official benchmark metric. No held-out model prediction has been executed or inspected.

## Proposed project metric `s55-project-ex-v1-proposed`

Run gold and generated Cypher separately on the same pinned Neo4j graph, with a dedicated read-only account and a 30-second transaction timeout. Maximum 10,000 result rows per side. Only a conservative read-only Cypher subset is admitted; external procedures, writes, comments and multiple statements are rejected. The graph mapping must be explicit. The evaluator returns `scored` with binary 0/1, `execution_error` (candidate incorrect, 0), `invalid_reference` (no score; blocks the analysis), or `unsupported` (no score; report separately). Empty/empty is a **one-instance pass only**, marked for diagnostic reporting. Empty/nonempty is incorrect. All-NULL and aggregate-zero matches are also weak one-instance evidence, not semantic equivalence.

Columns are compared **by position**, ignoring alias text. Arity must match. Row order is ignored even with `ORDER BY`; this deliberately evaluates result membership and multiplicity rather than presentation order. Duplicate rows are retained as a multiset. Each row remains an associated tuple; values are never flattened across columns. Numeric integers, finite floats and Decimal values compare with absolute tolerance `1e-9`, including nested lists/maps; booleans are distinct from numbers. NULL matches only NULL. Lists preserve order; maps compare string keys and corresponding values without map-key order. Python date/time/datetime compare by typed ISO representation. Graph nodes, relationships, paths, unknown Neo4j temporal/spatial values, non-finite numbers and unsupported types cause `unsupported`; no string fallback is allowed. This is an explicit conservative coverage limit. Even a positive result is **not proof of semantic query equivalence**.

The implementation is `evaluation/project_ex.py`; the adapter is `evaluation/score_predictions.py`. The evaluator's returned `metric` field and output manifest record version and source hashes. The model-output validator requires all 40 expected IDs, their order, unique membership, exact Qwen/Mistral revisions, frozen prompt/packet hashes, extraction consistency, decoder settings and explicit failed rows. A missing row invalidates the run; it is never silently scored as wrong or dropped. Gold Cypher is joined locally by unique MtQ ID and graph from the pinned manual test tree; it is never uploaded to Kaggle. Neo4j execution is **NOT TESTED** in S55B, because no isolated authorized graph/account was established in this session.

## Viability decision

For each model separately, count `scored` verdict 1 among the **fixed 40**. The threshold remains **at least 6/40**. Non-extractable generations, generation errors, prompt-too-long records and candidate execution errors contribute zero to the full denominator. `invalid_reference`, unsupported result values, missing/duplicate rows, graph mismatch, or infrastructure failure **invalidate the gate** pending a documented decision; they are not silently converted to wrong predictions. A model with fewer than six correct under a valid gate stops. A passing model may proceed to its remaining 260 only at a separate owner execution boundary, with the first 40 preserved exactly once. No tuning, retry for bad content, question replacement or change to the metric after observing scores.

The 84 frozen near-training-wording flags remain in the primary 300. The 216-ID sensitivity set is unchanged. If the full run occurs, compare applicable native-Cypher scorer verdicts on paired eligible questions, report raw denominators and unsupported outcomes, 10,000 paired question bootstrap replicates (seed 55), discordant counts and exact McNemar as secondary. The previously declared 2-point absolute practical-materiality threshold remains. Rankings alone do not satisfy it. Semantic adjudication is separate and blind. The scorer-impact script uses the suffix `_official` as its internal **baseline-column selector**; `s55_project_ex_official` in that CSV does **not** mean the metric is official Mind the Query scoring.

## Conflict and approval

S54's “official scorer” wording conflicts with the absence of a verified implementation. Approval A must explicitly accept replacing that term with the project-defined metric above **without changing 6/40**. If an official comparator is later verified before any held-out result is viewed, compare its policy with this proposal and obtain a new decision. The current metric is not authoritative for held-out execution until Approval A.
