# Pre-result near-training-wording resolution — frozen before inference

The 300-question Mind the Query packet was selected without scorer/model outputs. A token-set Jaccard threshold of **0.8** against its 4,254 manual-train questions flags **84** selected items; the same rule finds **22** internal near-duplicate pairs forming **280** connected clusters. The exact ID-only flags and 216 remaining IDs are frozen in `data/near_overlap_flags.csv` (SHA-256 `b4e98a11ac024ef84e959c75225874e76238ac4ffb0c202551d394ecbef563fa`) and `data/near_train_excluded_ids.json` (SHA-256 `ccde5a4e5eb181a54f2148e856199656aceee6a408c46a0f61d10836bf86a7fa`). No model prediction or scorer result existed when this choice was made.

**Primary:** retain all 300 preselected questions. The models receive no manual-train examples and no training/fine-tuning occurs, so near wording is not demonstrated train/evaluation leakage. Report the 84 and 22 counts prominently. **Sensitivity A:** recompute all accuracy, scorer-difference and discordance statistics on the fixed 216-ID subset, without replacing questions. This is a sensitivity analysis, not a new ≥300-question confirmatory population. **Sensitivity B:** bootstrap the 280 connected near-duplicate clusters, keeping both models and all scorers for each sampled cluster together; report alongside question-level intervals. No post-result threshold change or favorable-case exclusion is allowed.

A practical-effect claim requires the predeclared ≥2 percentage-point paired difference on the primary data and a directionally consistent effect on Sensitivity A; uncertainty from both question and near-cluster resampling must be shown. If the effect disappears or reverses after exclusion, state that the practical-significance claim is not robust. The 84 cases are never silently removed from the primary denominator.

This diagnostic cannot rule out latent model pretraining on public benchmark questions or semantic paraphrases below the token threshold. The limitation remains even if the sensitivity is stable.
